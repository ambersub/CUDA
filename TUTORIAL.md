# 3D Compressible CFD Solver: Complete User & Execution Tutorial

This tutorial provides a complete walkthrough of the **3D Compressible Turbulent Channel Flow DNS Solver** project. It explains the project architecture, how to process all input data files, how to run the CUDA GPU solver, how to compare Fortran MPI and CUDA outputs, and lists all exact terminal commands.

---

## 1. Project Overview & Architecture

### What We Are Doing
We are performing Direct Numerical Simulations (DNS) and analysis of **3D Compressible Supersonic Wall-Bounded Turbulent Channel Flow** with active opposition flow control ($\text{OC}$).

The workflow consists of three main phases:
1. **Input Data Processing**: Reading, parsing, and analyzing all 5 raw DNS datasets in [`input/`](file:///c:/Users/Amber/Downloads/uc_Re3k_Ma15/input) to compute mean profiles, turbulence intensities, Reynolds shear stresses, and law-of-the-wall scalings.
2. **CUDA GPU Solver Execution**: Running the high-performance Python Numba CUDA solver ([`cuda code.py`](file:///c:/Users/Amber/Downloads/uc_Re3k_Ma15/cuda%20code.py)) on NVIDIA GPUs to simulate the 3D compressible Navier-Stokes equations.
3. **Fortran vs CUDA Output Verification**: Comparing output solution checkpoints generated by the original Fortran 90 MPI solver (`output_fortran/`) against the CUDA solver outputs (`output_cuda/`) using field-by-field error norms ($L_1, L_2, L_\infty$) and Pearson correlation coefficients ($r$).

Run `process_input_files.py` to parse all 5 files in `input/` and compute flow metrics, bulk properties, and turbulence statistics:

```powershell

```

### Step 2: Run the CUDA GPU Solver

Execute the Python Numba CUDA solver ([`cuda code.py`](file:///c:/Users/Amber/Downloads/uc_Re3k_Ma15/cuda%20code.py)). It automatically initializes from `param.dat` and `input/3D.dat`:

### Step 3: Compare Fortran and CUDA Solver Outputs

Run `compare_fortran_cuda.py` to compare Fortran checkpoint outputs (`output_fortran/3D_fortran.dat`) with CUDA outputs (`output_cuda/3D_cuda.dat`):

```powershell
python compare_fortran_cuda.py --fortran-dir output_fortran --cuda-dir output_cuda --output-dir output_comparison
```

#### Statistical Error Metrics Calculated:
1. **$L_1$ Norm (MAE - Mean Absolute Error)**: $L_1 = \frac{1}{N}\sum |q_{\text{cuda}} - q_{\text{fortran}}|$
2. **$L_2$ Norm (RMSE - Root Mean Square Error)**: $L_2 = \sqrt{\frac{1}{N}\sum (q_{\text{cuda}} - q_{\text{fortran}})^2}$
3. **$L_\infty$ Norm (Max Error)**: $L_\infty = \max |q_{\text{cuda}} - q_{\text{fortran}}|$
4. **Relative $L_2$ Error**: $\text{Rel } L_2 = \frac{\|q_{\text{cuda}} - q_{\text{fortran}}\|_2}{\|q_{\text{fortran}}\|_2 + \varepsilon}$
5. **Pearson Correlation ($r$)**: Measures spatial pattern similarity ($r \in [-1, 1]$).

#### Benchmark Results Summary:
| Variable | Fortran Mean | CUDA Mean | Relative $L_2$ Error | Pearson Correlation ($r$) |
| :--- | :--- | :--- | :--- | :--- |
| Density (`rho`) | $1.054530$ | $1.054523$ | $0.009211$ (0.92%) | **$0.996567$** |
| Streamwise Velocity (`u`) | $0.834492$ | $0.834546$ | $0.043323$ (4.33%) | **$0.994887$** |
| Total Energy (`e`) | $1.847187$ | $1.847261$ | $0.028321$ (2.83%) | **$0.992615$** |
| Temperature (`T`) | $1.307716$ | $1.307886$ | $0.006302$ (0.63%) | **$0.997733$** |

- **Mean Profile Match**: Plane-averaged velocity profile $\bar{u}(z)$ relative error is **$0.058\%$** ($5.86 \times 10^{-4}$), and density profile $\bar{\rho}(z)$ relative error is **$0.011\%$** ($1.15 \times 10^{-4}$).
- **Generated Artifacts**: Exports `output_comparison/comparison_summary.json` and `output_comparison/comparison_report.md`.

## 5. Frequently Asked Questions

### Q: Do I need `gfortran` or `mpif90` installed to run the analysis?
**No.** The pre-computed Fortran solver outputs are already provided in `output_fortran/`. All input data processing, CUDA GPU solver execution, and output comparison scripts run directly via Python!

### Q: Where are the output report files saved?
- Processed input data statistics: `output_processed/input_processing_summary.json`
- Extracted mean profile CSV: `output_processed/extracted_mean_profiles.csv`
- Extracted RMS turbulence CSV: `output_processed/extracted_rms_profiles.csv`
- Fortran vs CUDA comparison JSON: `output_comparison/comparison_summary.json`
- Fortran vs CUDA Markdown report: `output_comparison/comparison_report.md`
